# Trackin360 landing page

A responsive React/Vite concept landing page for electronic monitoring solutions. Product artwork and dashboard content are illustrative; the Google Maps preview shows a fictional public demo area in San Francisco, not a device or person's location. Nothing on this page performs live tracking or represents verified product specifications or platform capabilities.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Before publishing

- Verify device models, specifications, networks, capabilities, integrations, and platform behavior with product documentation.
- Replace illustrative product art and dashboard data with approved, licensed assets and verified product material.
- Confirm the actual login URL, company details, privacy policy, terms, and accessibility information.
- Document and validate the deployment's authentication, authorization, encryption, audit logging, and data retention controls.
- The embedded Google Maps preview is served by Google and may connect visitors' browsers to Google. Review third-party privacy requirements before publication.

The login link points to the public Trackin360 manager URL supplied in the project brief. This page does not expose or implement private monitoring functionality.
